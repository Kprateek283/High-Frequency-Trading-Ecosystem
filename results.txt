# ---- How to read the numbers above ----
#
# This is a FUNCTIONAL run: a deterministic crossing driver (tools/liquidity)
# proving the pipeline matches orders end to end. The counts (NEW, matches,
# FILLED, REJECTED) are the point. The timings are not a latency benchmark,
# for three specific reasons:
#
# 1. UDP Path / Trading Engine / SPSC Queue read 0 BY CONSTRUCTION.
#    liquidity.cpp stamps t1=t2=t3=t4 with a single send-time TSC because it
#    has no firm-side pipeline to measure. Only t5-t4 (TCP path) is real here.
#    For a populated five-point decomposition, drive the exchange with the
#    trading firm (LocalExchangeConnector), which stamps each stage separately.
#
# 2. TCP path and end-to-end are BURST QUEUEING DELAY, not per-order latency.
#    liquidity stamps every order at send time and blasts 20k of them
#    unthrottled, so the gateway drains a backlog it never had a chance to
#    keep up with. t5-t4 therefore grows through the burst and its average is
#    roughly half the total drain. It measures the queue, which is real, but
#    it is not the number to quote for network latency.
#
# 3. The gateway cycle attribution here is NOT comparable to
#    cycle_attribution.txt. epoll_wait in particular is inflated: this run is
#    ~95% idle and amortises blocking time over only 20k orders, where the
#    sustained sweep amortises it over millions. Use cycle_attribution.txt
#    for per-stage cost; use this file for correctness.
#
# Gateway ingest throughput sweep (workers x clients): see
#   benchmark_results.txt (regenerate with scripts/measure_throughput.py).
# For the latency matrix across shard counts, re-run this script with
#   GATEWAY_THREADS=1 / 2 / 4 / 8.
#
# NOTE: absolute latency/throughput here are a LOWER BOUND unless the box
#   grants SCHED_FIFO (ulimit -r) and uses the 'performance' governor with
#   isolated cores. The measurement code is complete; the numbers become
#   publishable only on such hardware (docs/benchmarks.md, Phase 3.5).
#
# RT_SCHED threads=N above is the readiness barrier's own denominator. If it
#   is short of 11 for this run, READY fired early and the numbers
#   below it describe a partially-started engine.
